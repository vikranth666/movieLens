# 🎬 Movie Lens

Movie Lens is a React-based movie search application that allows users to search for movies and view detailed information in real time using the **OMDb API**.

# Live

Vercle : https://movielens-neon.vercel.app/
---

## Features

-  **Movie Search** with debounced input for better performance  
-  **Movie Cards** with poster, title, and release year  
-  **Detailed Movie Modal** (plot, rating, runtime, cast, awards)  
-  **Loading & Error Handling** states  
-  **Modern UI** built with Tailwind CSS  
-  **React Hooks** (`useState`, `useEffect`)  
-  **OMDb API Integration**

---

##  Tech Stack

- **React**
- **JavaScript (ES6+)**
- **Tailwind CSS**
- **Vite**
- **OMDb API**
- **Lucide Icons**
